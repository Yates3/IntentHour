# Checksums

`SHA256SUMS.txt` identifies the final local Windows Desktop Preview installer used for the release draft. The installer itself is intentionally excluded from this lightweight showcase archive.

The [`desktop-v1.0.0` GitHub prerelease](https://github.com/Yates3/IntentHour/releases/tag/desktop-v1.0.0) contains the installer and checksum from the same build. Regenerating the installer requires regenerating and updating the checksum.
