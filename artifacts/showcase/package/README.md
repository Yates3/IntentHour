# IntentHour Project Showcase Package

This directory contains a lightweight, public-safe snapshot of IntentHour's product story, architecture, verified validation results, Windows Desktop Preview release notes, demo script, links, screenshots, and checksums.

It intentionally excludes:

- installers and update packages;
- source code and dependencies;
- environment files and provider credentials;
- local databases and user data;
- generated logs and test reports.

The generated archive is `artifacts/showcase/IntentHour-Project-Showcase.zip`. Source documents in the repository remain authoritative when this snapshot becomes stale.
