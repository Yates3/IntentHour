# IntentHour Desktop Preview 1.0.0

IntentHour Desktop is a local-first Windows focus client for protecting one concrete outcome at a time.

## Included

- Start, pause, resume, complete, or discard a local focus Session.
- Record interruption categories without monitoring the screen or other apps.
- Restore an active Session after a full application restart.
- Keep completed and discarded Sessions in local Desktop history.
- Close to the Windows system tray and restore the existing single instance.
- Receive one native reminder when a running Session reaches its target.

## Preview limits

- Windows x64 only.
- Local guest mode only; no Desktop account, cloud sync, Pro, billing, or AI review.
- No automatic updater.
- The installer is not code-signed. Windows SmartScreen may show a warning.

Verify `IntentHour-Setup-1.0.0.exe` against `SHA256SUMS.txt` before installing. Only download the preview from the official IntentHour GitHub Release after that release has been published.
